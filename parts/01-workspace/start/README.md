# Shipyard

Shipyard is a small release-management toolkit built live during the Claude Code Bootcamp (Cohort 2):

- `shipctl` — a command-line release task manager (Project 2)
- a Notes API for engineering and release notes (Projects 4–6)
- a release dashboard (Projects 7–8, 9C)

Everything uses the Python 3 standard library and plain HTML/JavaScript. No package installs.

## Requirements

- Python 3.10+
- Node.js 18+ (dashboard tests only)
- Git

The human who reviews and merges a change is the engineer of record. Claude proposes; the engineer of record decides.
